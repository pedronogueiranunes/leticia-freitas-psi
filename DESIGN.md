# Design

Incumbent system, recorded from `css/styles.css`. Refinement preserves it.

## Color
- Primary/CTA: sage `#4A7B5E` (`--brown-btn`, `--accent-italic`); deep `#3a6b4e`, `#2d5540`.
- Surfaces: white `#ffffff`, `--warm-white #f5faf6`, `--cream #edf4ef`, `--card-bg #deeee6`.
- Text: `--text-dark #1a2e25`, `--text-mid #3d5e4e`, `--text-light #7aa898` (decorative only, fails contrast for body).
- Border: `--border-green #cce4d4`.

## Type
- Display: Playfair Display 400/600/700 + italic 400 for accent words.
- Body/UI: DM Sans 300–600.

## Shape
- Large radii (nav pill 34px), 1px green borders, soft sage shadow `4px 6px 19px #4a7b5e24`.
- Icons: Lucide, no emojis.
